## About Me

I am building my career toward becoming a **SOC Analyst**, with a focus on defensive cybersecurity, security monitoring, log analysis, threat detection, and incident investigation. I develop my skills through hands-on labs, security investigations, technical research, and detailed documentation, using GitHub to document my practical work and demonstrate how I approach security problems.

---

## Objective

My objective is to become a job-ready SOC Analyst capable of monitoring security environments, triaging alerts, analyzing logs and network activity, investigating suspicious behavior, identifying indicators of compromise, correlating evidence, and communicating findings through clear and professional security reports.
